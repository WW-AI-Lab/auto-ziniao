# 自愈机制与提示词模板

## 触发链路

```
流程最终失败（流程级重试耗尽）
  │
  ├─ CLI --no-heal 或 flow.on_fail_final.heal=false → 不触发
  │
  ├─ check_known_issues：错误匹配已解决问题（pattern 子串 或 flow_id+step_id）
  │     命中 → 打印修复方案，不触发 Agent（0 tokens）
  │
  ├─ 失败现场截图（店铺仍开着时，take_screenshot 尽力而为）
  │
  ├─ check_cooldown：同流程同步骤 60 分钟内已触发过 → 跳过
  │                  该流程今日已触发 ≥5 次 → 跳过
  │
  └─ 渲染提示词 → 写 data/logs/heals/<heal_id>_prompt.md
       → subprocess 调用 config.json 配置的 Agent CLI
       → 事件写 learnings/heals.jsonl
```

## 错误类型与分类规则（self_heal.classify_error）

| error_type | 触发条件 | 模板要点 |
|------------|----------|----------|
| `auth_failed` | 401/403/api key/unauthorized | 检查 ZCLAW_API_KEY；站点登录态过期需人工 |
| `timeout` | timeout/超时 | 调大 timeoutMs；首次开店需下载内核 1-5 分钟 |
| `element_not_found` | not found/selector/校验失败/结果为空 | 截图看改版/弹窗；query_elements 探索新选择器 |
| `nav_failed` | 工具是 visit_page 或步骤 id 含 nav | 看跳转/404/登录页；从站内菜单找新 URL |
| `extract_failed` | 工具是 execute_script 或步骤 id 含 extract | 对比提取 JS 与实际 DOM；兼容中英文 |
| `bridge_down` | 连接失败/connection refused | 环境问题，提示启动紫鸟客户端，勿改流程 |
| `generic` | 其他 | 通用诊断步骤 |

步骤可在 `on_fail.context` 显式指定错误类型，优先于自动分类。

## 提示词组装（四层）

```
① 通用前缀（内置）     任务清单 + 失败现场（流程/步骤/错误/参数/入参/截图路径）
                      + 安全约定（只走 ZClaw bridge、不臆造工具名、IIFE、修复后必须验证）
② 错误类型模板         heal_templates/<error_type>.md（可编辑定制）
③ 流程级 hints        flow JSON 的 heal.hints —— 沉淀时编写的页面线索
④ 修复闭环指令（内置）  validate → run -v --no-heal 验证 → 写 known_issues → 通知
```

### 模板查找顺序（支持按流程定制）

```
heal_templates/<flow_id>/<error_type>.md    ← 流程专属、错误类型专属
heal_templates/<flow_id>/generic.md         ← 流程专属兜底
heal_templates/<error_type>.md              ← 全局错误类型模板（默认已生成 7 个）
heal_templates/generic.md                   ← 全局兜底
内置默认模板（engine/self_heal.py）           ← 文件都不存在时
```

模板是 Markdown，可用占位符：`{flow_id}` `{flow_name}` `{step_id}` `{tool_name}` `{error}` `{error_type}` `{timestamp}` `{params}` `{failed_args}` `{screenshot}` `{scripts_dir}` `{heal_log_path}`。未知占位符保留原样不会报错。

### 沉淀时的提示词义务

每个新流程**必须**在 flow JSON 写 `heal.hints`，内容包括：
1. 目标页面入口（URL 或菜单路径）；
2. 关键选择器/正则及其含义；
3. 页面结构特征（如"React 组件无传统 table，需用 innerText 解析"）；
4. 已知的坑（语言切换影响正则、弹窗遮挡、重定向等）。

复杂流程可再加 `heal_templates/<flow_id>/<error_type>.md` 做深度定制。

## Agent CLI 配置（config.json）

```json
{
  "heal": {
    "enabled": true,
    "agent": "openclaw",            // 默认使用哪个 Agent
    "cooldown_minutes": 60,
    "max_per_day": 5,
    "agents": {
      "openclaw":     { "command": ["openclaw", "agent", "--session-key", "{session_key}", "--message", "{prompt}", "--deliver", "--channel", "feishu", "--timeout", "300"], "timeout_sec": 320 },
      "claude":       { "command": ["claude", "-p", "{prompt}", "--allowedTools", "Bash,Read,Write,Edit"], "timeout_sec": 600 },
      "cursor-agent": { "command": ["cursor-agent", "-p", "{prompt}"], "timeout_sec": 600 }
    }
  }
}
```

- 命令占位符：`{prompt}`（完整提示词）、`{prompt_path}`（提示词文件路径，提示词过长时建议改用它）、`{session_key}`、`{flow_id}`、`{heal_id}`。
- 切换 Agent：改 `heal.agent`，或手动触发时 `python3 -m engine.self_heal --flow-id xxx --agent claude`。
- 手动调试：`python3 -m engine.self_heal --flow-id xxx --step-id yyy --error "..." --dry-run` 只生成提示词不调用。

## 自愈 Agent 的修复闭环（提示词中强制要求）

1. 诊断：通过 ZClaw bridge 操作紫鸟浏览器复现/截图/读 DOM；
2. 修复：改 `flows/<id>.json` 或 `extracts/*.js`，版本号 +1；
3. 校验：`python3 manager.py validate <id>`；
4. 验证：`python3 manager.py run <id> -v --no-heal` 必须真实跑通；
5. 固化：把修复写入 `learnings/known_issues.json`（pattern 取错误信息中稳定的子串）；
6. 通知用户结果。

## known_issues.json 格式

```json
{
  "issues": [
    {
      "pattern": "缺少必需字段: accountHealthRating",
      "flow_id": "account_health",
      "step_id": "extract_health_data",
      "root_cause": "Amazon 账户状况页改版，评级数字位置变化",
      "fix": "更新 extracts/extract_account_health.js 的评级正则",
      "fix_applied_at": "2026-06-12T18:00:00",
      "resolved": true
    }
  ]
}
```

`resolved: true` 的条目参与命中匹配；命中即不再触发 Agent。若同类问题再次出现且确认旧方案失效，应把旧条目改为 `resolved: false` 后重跑以重新触发自愈。

## 日志与排查

| 文件 | 内容 |
|------|------|
| `data/logs/heals/<heal_id>.json` | 失败上下文（给 Agent 读） |
| `data/logs/heals/<heal_id>_prompt.md` | 完整提示词（人工 review 用） |
| `learnings/heals.jsonl` | 触发/跳过事件流（冷却判断依据） |
| `manager.py heals` | 查看最近 20 条自愈事件 |
