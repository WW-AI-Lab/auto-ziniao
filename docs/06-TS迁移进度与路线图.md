# TypeScript 迁移进度与路线图

> 状态日期：2026-06-14  
> 目标：用一个专门文件跟踪 TS 迁移当前状态、已完成边界、下一步 OpenSpec change 和剩余工作。长期架构设计仍以 `docs/05-TS重构技术蓝图.md` 为准。

### M4：Self-Heal 迁移

已由 OpenSpec change `add-typescript-self-heal` 落地：

- `packages/self-heal`
- `classifyError()`：兼容 Python 自愈错误分类
- `checkKnownIssues()`：读取 `learnings/known_issues.json`，支持 `resolved: true`、`pattern` 子串和 `flow_id + step_id` 命中
- `buildHealPrompt()`：生成 `data/logs/heals/<heal_id>.json` 和 `data/logs/heals/<heal_id>_prompt.md`
- `heal_templates/` 模板优先级和 safe placeholder rendering
- `loadHealConfig()`：兼容 Python 默认配置与 `config.json` 浅合并，只读不写
- `checkCooldown()` 与 `learnings/heals.jsonl` 事件写入
- `AgentRunner` / `createCommandAgentRunner()`：支持 command placeholder、timeout、non-zero exit、command missing
- `triggerHeal()`：支持 dry-run、disabled、known issue skip、cooldown skip、mock runner trigger
- `buildTriggerInputFromFailure()`：从 M3 flow-engine failure metadata 组装 self-heal 输入
- `packages/core` 新增 JSON/JSONL 写入 helper
- `packages/schemas` 扩展 heal context/event 兼容字段
- 安全扫描新增 `packages/self-heal` 禁止依赖/import `@ziniao/zclaw` 的规则

验收状态：

- `pnpm typecheck`
- `pnpm test`
- `pnpm build`
- `pnpm security:scan`
- `pnpm validate:baseline`
- 精确边界检查：`rg -n "9481|/zclaw/tools|/zclaw/" packages/self-heal/src` 无命中
- `python3 manager.py list`
- `python3 manager.py validate orders_overview`
- `openspec validate add-typescript-self-heal --strict`

M4 dry-run 边界：

- dry-run 会生成 `data/logs/heals/<heal_id>.json` 与 `data/logs/heals/<heal_id>_prompt.md`。
- dry-run 不调用真实 Agent CLI，不消耗 cooldown quota，不追加 `triggered` 事件。
- 默认 baseline 使用 mock `AgentRunner`、临时 data root 和固定 clock，不调用 OpenClaw/Claude/Cursor。

M4 回滚验证记录：

- 等价回滚检查：`git diff --name-only -- manager.py engine webadmin` 无输出，确认 Python 生产入口、engine 与 WebAdmin 未被 M4 修改。
- 回滚方式：删除或隔离 `packages/self-heal`，恢复 root `package.json`、`tsconfig.base.json`、`vitest.config.ts` 与 `scripts/security-scan.ts` 中的 M4 改动。
- 回滚后基线：`python3 manager.py list` 与 `python3 manager.py validate orders_overview` 已通过。

## 当前边界

当前仍未改变生产路径：

- `manager.py` 仍转发到 Python `engine/manager.py`
- 真实 flow 执行仍由 Python `engine/flow_engine.py` 完成
- 自愈仍由 Python `engine/self_heal.py` 完成
- WebAdmin 后端仍是当前 FastAPI 子工程
- TS `packages/flow-engine` 与 `packages/self-heal` 仅作为后续 CLI/WebAdmin 切换前的执行和自愈基础能力

当前禁止事项：

- 不得把生产入口切到 TS。
- 不得在 baseline 验证中执行真实 flow。
- 不得在 baseline 验证中调用真实 `POST /zclaw/tools/invoke`。
- 不得在 baseline 验证中调用真实 OpenClaw/Claude/Cursor Agent CLI。
- 不得绕过 `packages/zclaw` 直接访问 ZClaw bridge。
- 不得引入 Playwright/Selenium/Puppeteer/browser-use。

## 下一步：M5 CLI

建议新建 OpenSpec change：`add-typescript-cli`。

目标范围：

- 新增 `packages/cli`
- 提供 `ziniao ...` 命令
- 兼容当前 `manager.py` 命令语义

M5 非目标：

- 不在未经双跑验证前替换 `python3 manager.py ...`。

## 回滚原则

- M1/M2 均不改变 Python 生产执行链路。
- M3 在完成双跑切换前也不得替换生产入口。
- M4 也不得替换生产入口；回滚可删除或隔离 `packages/self-heal`，恢复 root script/path alias/security scan 改动。
- 任一阶段回滚时，优先删除或隔离对应新增 TS 包，并恢复 root scripts、alias 与安全扫描规则。
- 回滚后必须验证：

```bash
python3 manager.py list
python3 manager.py validate orders_overview
```
